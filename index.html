💻 Run Directly from Python CLI

AutoClipper can be executed directly in your terminal for automation, scripts, or local OBS recording folders: 

# 1. Clip any YouTube stream or video
python autoclipper.py "https://www.youtube.com/watch?v=VIDEO_ID" --clip-duration 45 --facecam top-right

# 2. Run with browser cookies for protected/member streams
python autoclipper.py "https://www.youtube.com/watch?v=VIDEO_ID" --cookies-from-browser chrome

# 3. Clip local recording (e.g. OBS Studio output)
python autoclipper.py "/path/to/stream_recording.mp4" --output-dir my_clips

# 4. Instant offline demo
python autoclipper.py --demo
